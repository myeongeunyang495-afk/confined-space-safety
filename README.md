# 밀폐공간 작업 안전신호등 · 원스톱 안전관리 웹앱

현장 작업자가 **작업개소를 먼저 선택한 뒤**, 해당 장소의 작업 전 안전상태·장비·담당부서·작업허가 절차를 한 화면에서 확인할 수 있도록 만든 정적 웹앱입니다.

## 기본 사용 흐름
**① 작업개소 선택 → ② 안전신호등 확인 → ③ 역할·6개 안전항목 확인 → ④ 장비·부서 확인 → ⑤ 작업허가 확인**

반기 대응훈련 시에는 상단 `🧯 대응훈련` 메뉴에서 현재 선택한 작업개소를 불러오거나 별도 장소를 선택하면 장소별 훈련 시나리오가 자동 생성됩니다.

## 핵심 기능
- 작업개소 선택 후 연동되는 작업 전 안전신호등: ⛔ 작업 중지 / ⚠ 확인 필요 / ✅ 작업 전 확인 완료
- 밀폐공간 검색 및 GPS 주변 찾기
- 작업자·발주/관리부서·감시인 역할별 안내
- 작업허가서, 가스농도측정기, 측정결과, 보호구·구조장비, 환기·감시인·연락수단, 작업자 안전인지 확인
- 관리부서·작업부서·협조부서 및 장비 현황 조회
- 지정 YouTube 안전영상 바로보기 + 임베드 차단 시 새 창 열기
- 밀폐공간작업 출입 허가서 작성·저장·인쇄/PDF
- 엑셀 데이터 업로드 및 브라우저 반영
- 큰 글씨 모드
- 반기 밀폐공간 대응훈련 시나리오 자동 생성 및 결과 저장·인쇄/PDF

## 안전영상
웹앱의 `▶ 안전영상 보기` 버튼은 아래 지정 영상으로 연결됩니다.

- https://www.youtube.com/watch?v=RlCXqNXBWtI
- 앱 내부 재생: YouTube Privacy-Enhanced Mode(`youtube-nocookie.com`) 임베드 사용
- 사내망·브라우저 정책으로 임베드가 차단될 경우 `YouTube에서 크게 보기` 버튼으로 원본 페이지를 엽니다.

영상은 작업 전 이해를 돕는 보조자료이며, 영상 시청만으로 작업허가·가스측정·환기·감시인 배치·보호구 착용·특별안전보건교육 등이 완료된 것으로 처리되지 않습니다.

## GitHub Pages 배포
1. 새 저장소 생성
2. `index.html`, `README.md`, `docs` 폴더 업로드
3. `Settings → Pages`
4. `Source → Deploy from a branch`
5. `Branch → main`, `Folder → /(root)` 선택 후 Save
6. 발급된 HTTPS 주소를 휴대전화에서 확인

## 외부 서비스 의존성
- YouTube / youtube-nocookie.com
- Google Fonts
- Leaflet
- SheetJS(XLSX)
- OpenStreetMap / Overpass API

## 저장 방식 주의
현재 버전은 정적 웹앱이며 엑셀 업로드 데이터, 작업 전 체크상태, 역할 선택, 디지털 작업허가서와 대응훈련 결과는 사용자 각자의 브라우저 `localStorage`에 저장됩니다. 다른 휴대전화와 자동 공유되지 않습니다.

## GPS 정보 주의
원본 엑셀에는 위도·경도가 없으므로 GPS 주변 찾기는 OpenStreetMap 철도역·철도시설 좌표와 시설명을 매칭한 참고 기능입니다.

## 보안 주의
`index.html` 안에는 밀폐공간 위치, 관리번호, 담당부서, 작업정보 및 장비현황이 내장되어 있습니다. 외부 공개 전에 조직의 정보공개·보안 기준을 확인하십시오.

## 안전상 주의
초록색은 **앱의 작업 전 확인항목이 입력상 완료됨**을 뜻하며 작업 자체의 안전을 보증하지 않습니다. 실제 작업 시 최신 사내 기준과 현장 관리감독자의 확인을 우선 적용하십시오.
